# Tirupati Fashion Store 👕

A beautiful clothing store demo built using Vibe Coding with Bolt.

**Live Demo:** https://clothing-store-landi-8hbb.bolt.host

## What I Built
- Modern clothing store landing page
- Product listing with prices in Rupees
- Cart & Checkout UI
- Mobile-friendly design

## Built With
- React + Vite + Tailwind CSS
- Bolt.new (AI Vibe Coding)

## How to Run
1. Clone this repo
2. Run `npm install`
3. Run `npm run dev`
